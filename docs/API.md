
# API категорий товаров проекта «Бери»

## 1. Назначение

API категорий товаров предназначен для получения списка категорий и информации об отдельной категории.

API реализован с помощью Django REST Framework. Создание и изменение категорий выполняется через административную панель Django.

## 2. Получение списка категорий

Метод: GET

Адрес: /api/categories/

Назначение: получение всех категорий товаров.

Пример ответа (HTTP 200 OK):

[
    {"id": 2, "name": "Бытовая техника"},
    {"id": 1, "name": "Инструменты"},
    {"id": 3, "name": "Развлечения"}
]

Поля ответа:
- id — уникальный числовой идентификатор BIGINT.
- name — название категории, максимум 100 символов.

Категории сортируются по названию в алфавитном порядке.
Если категорий нет, возвращается пустой список [].

## 3. Получение одной категории

Метод: GET

Адрес: /api/categories/{id}/

Назначение: получение категории по её ID.

Пример запроса:

GET /api/categories/1/

Пример ответа (HTTP 200 OK):

{
    "id": 1,
    "name": "Инструменты"
}

Если категория не найдена, возвращается HTTP 404 Not Found.

## 4. Доступные методы

API предназначен только для чтения данных.

Поддерживаемые методы:
- GET — получение данных.
- HEAD — получение заголовков ответа.
- OPTIONS — информация о доступных методах.

Методы POST, PUT, PATCH и DELETE запрещены.
При попытке их использования возвращается HTTP 405 Method Not Allowed.

Запросы на получение категорий не изменяют записи в базе данных.

## 5. Авторизация и права доступа

В текущей реализации дополнительные ограничения доступа к API категорий не установлены.

При текущих настройках Django REST Framework получение категорий доступно без авторизации.

Добавлять, изменять и удалять категории можно через Django Admin при наличии соответствующих административных прав.

Правила доступа могут быть уточнены при интеграции с модулем Account.

## 6. Проверка API

Реализованы четыре автоматических теста:

1. Получение списка категорий.
2. Получение категории по ID.
3. Проверка уникальности названия.
4. Запрет создания категории через API.

Команда запуска:

    python manage.py test apps.catalog

Результат: все четыре теста успешно пройдены.

Дополнительно подтверждено:
- GET /api/categories/ — HTTP 200 OK.
- GET не изменяет данные категорий.

## 7. Примечание по интеграции

Текущий реализованный адрес: /api/categories/.

В расширенном регламенте разработки также указан префикс /api/v1/.

Окончательный адрес необходимо согласовать с командой перед интеграцией.
